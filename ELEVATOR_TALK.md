# Modern JavaScript and TypeScript

## Abstract

After 15 years of JavaScript winter, ES2015 changed everything, but what happened since? This code-show walks through every ECMAScript release from ES2016 to ES2025 using live Vitest specs: Array.prototype additions, Promise and RegExp features, optional chaining, top-level await and more. The second half is a thorough TypeScript introduction: type vs interface, narrowing and discriminated unions, tuples, records and enums, indexers and utility types, generics with constraints and recursion, template literal types and function overloads. Optional extras cover debugging (console API, Chrome, VS Code), linting and typing third-party code with d.ts files and JSDoc. Length scales with how many years of ECMAScript fit in the slot.

## Elevator pitch

Everybody knows ES2015. But what has JavaScript gained since? A live, test-driven tour of ES2016–ES2025 plus a TypeScript type-system crash course.

## Outline

- A history of JS: 1991 first website → ES3 → the long JavaScript winter (1999–2015) → ES2015
- ES2016–2018 recap
- ECMAScript 2019 → 2025, one spec file per year (code-show)
- TypeScript: why, type vs interface, narrowing, discriminated unions
- Tuples, records, enums, indexers and utility types
- Generics, immutability, template literal types, function overloads
- Extras: debugging JS, linting, d.ts / JSDoc typing, monorepos
